# AADS - Advanced Animation Director System (Web Wrapper)

This repository contains the open-source web interface and API routing for **AADS (Advanced Animation Director System)**, developed for the Agentic Cinema Hackathon. 

This application is built to run on **Replit** and utilizes the **Google GenAI SDK (Gemini)** to process user input and act as the cognitive directing agent.

### Open Source vs. Proprietary Core
Please note: This repository utilizes a "Split Strategy" to protect core intellectual property. 

* **Open Source (This Repo):** Contains the Replit-hosted web application, user interface, and the Google Gemini API integration routes. It is licensed under the MIT License.
* **Closed Source (Proprietary):** The underlying AADS V25.6 Canonical Master System—which contains 8 months of proprietary Visual Kinematic Language (VKL) routing rules, Character DNA genomes, and Causal Intensity Scaling algorithms—remains closed-source and is securely accessed by the application at runtime.
